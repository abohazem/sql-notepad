SQL Notepad @Yosri

A quick online workspace for SQL & notes — no install needed.

This tool exists to make everyday editing fast and frictionless. Instead of opening a heavy local desktop application for a quick query or a short note, you open one page in your browser and start working in seconds.

It's built for quick, lightweight tasks:

  • Write and clean up SQL with syntax highlighting
  • Keep quick notes alongside your code in tabs
  • Switch between 15+ languages on the fly
  • Search, replace, and highlight matches instantly
  • A built-in calculator for quick math while you work

Everything runs in your browser. Your open tabs are saved locally, so you can close the page and pick up where you left off.
